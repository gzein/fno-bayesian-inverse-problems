# Bayesian Inverse Problems for Darcy Flow with Fourier Neural Operators

Code accompanying my MSc dissertation, *Bayesian Non-linear Inverse Problems for PDEs with Neural Operator Surrogates* (Imperial College London, 2026).

We solve the Bayesian inverse problem for Darcy's law - recovering the diffusion
coefficient from noisy observations of the flow field - using a Fourier Neural
Operator (FNO) as a fast surrogate for the forward PDE solve inside a pCN MCMC
sampler. The repository reproduces all figures and tables in Chapter 4, plus the
preliminary McKean-Vlasov results in Chapter 5.

## Repository structure

```
Darcy_FNO.ipynb               Main pipeline: train FNO, run pCN MCMC, UQ figures (4.2–4.5)
Darcy_Ablation.ipynb          Ablation studies over Fourier modes and observation sparsity (4.7, 4.8)
McKeanVlasov.ipynb            Preliminary non-linear results (Chapter 5)
McKeanVlasov_data.ipynb       Generates data for McKean-Vlasov problem
FNO_PINO_Darcy.ipynb          Experiments with PINO on FNO
FEM_Darcy.ipynb               Running exact FEM for Darcy's problem
```

## Installation

```bash
git clone https://github.com/gzein/fno-bayesian-inverse-problems.git
cd <repo>
pip install -r requirements.txt
```

Tested with Python 3.11 and PyTorch 2.x. Training was run on an NVIDIA RTX 5060
laptop GPU; a GPU is recommended but the notebooks run on CPU.

## Data

The Darcy flow dataset is from the NeuralOperator team (Zenodo,
[doi:10.5281/zenodo.12784353](https://doi.org/10.5281/zenodo.12784353)).
The McKean-Vlasov dataset is generated by the included finite-difference solver (`src/mckean_vlasov.py`).

## Reproducing the results

| Result | Notebook | Approx. runtime |
|--------|----------|-----------------|
| Single-sample inference (Fig 4.2–4.5, Table 4.2–4.3) | `Darcy_FNO.ipynb` | ~20 min |
| Fourier-mode + sparsity ablations (Fig 4.7–4.8) | `Darcy_Ablation.ipynb` | ~8 hr (retrains FNO per mode) |
| McKean-Vlasov (Fig 5.1) | `McKeanVlasov.ipynb` | ~10 min |

Run the cells top to bottom. The FNO trains in ~2.5 min; the full MCMC run is
100,000 iterations.
